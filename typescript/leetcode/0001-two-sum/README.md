# 1. Two Sum

https://leetcode.com/problems/two-sum/

## 方針

二重ループで全ペアを試すと O(N²)。「a + b = target」は「b = target - a」と同じなので、
探すのはペアではなく**片方の相方 1 つ**でよい。

左から 1 周しながら「値 -> 添字」を Map に入れていき、各要素で `target - nums[i]` が
既に Map にあるかだけ見る。あればそのときの添字と今の添字が答え。
先に入れてから探すと自分自身とペアにしてしまうので、**探してから入れる**順にする。

## 計算量

- 時間: O(N)（Map の get / set は平均 O(1)）
- 空間: O(N)

## 学び

- ペアを探す問題は「差・和が決まっている＝相方が一意に決まる」なら Map で 1 周に落ちる
- ハッシュに入れるタイミングは 1 行で正誤が変わる。自分自身を使ってしまう事故は
  「探す → 入れる」の順で防げる
